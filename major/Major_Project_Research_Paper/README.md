# Major Project Research Paper

Research Paper: *Benchmarking Phase Ordering Trade-offs in a Custom Compiler Infrastructure using MiBench*

## Active Files
- **`Revised Paper (Final).tex`** — The active, primary IEEE conference paper LaTeX source.
- **`Revised Paper (Final).pdf`** — The compiled final PDF paper.
- **`fig/`** — High-resolution figures and benchmark plots referenced by the paper.
- **`build.ps1`** — PowerShell script to build the final paper in two passes with `pdflatex`.

## Build
Run in PowerShell:
```powershell
.\build.ps1
```
Or manually:
```bash
pdflatex "Revised Paper (Final).tex"
pdflatex "Revised Paper (Final).tex"
```

## Archive
- **`archived/`** — Contains older drafts, experiments, and intermediate revisions (e.g. initial 6-page draft, full versions, un-anonymized and without-author versions).
